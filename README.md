A static portfolio built with semantic HTML, CSS, and lightweight JavaScript.

## Live site

- Portfolio: [sammiller.netlify.app](https://sammiller.netlify.app/)
- LinkedIn: [linkedin.com/in/booleanmethods](https://www.linkedin.com/in/booleanmethods/)

The portfolio is hosted on Netlify. The repository root contains the current site; open `index.html` directly or run `python -m http.server 8000` and visit `http://127.0.0.1:8000` for a local preview.

## Disclosure and privacy

Professional work is summarized at a high level. These summaries are descriptions of experience, not public releases of employer systems. Work is presented in compact responsive rows with keyboard-accessible technical-detail dropdowns. Expandable notes cover general techniques only; internal metrics, storage paths, schemas, approval rules, and operational details are intentionally omitted. Anonymization alone does not establish permission to disclose work under an NDA. Client code, security findings, internal screenshots, and internal artifacts are not published here. This is a personal portfolio, not an official Macy&rsquo;s website or statement on the company&rsquo;s behalf. Names and marks identify tools and organizations; their respective owners retain them, and no sponsorship or endorsement is implied.

Both the Server Vulnerability Assessment and Incident Response Plan are bachelor's capstone projects completed as academic coursework. The public Server Vulnerability Assessment identifies the classroom-lab context and removes the VM MAC address and Greenbone report ID from the embedded screenshot pixels. Unmodified originals are preserved locally outside the published site; older Git commits and deployments can retain earlier copies. The Cyber Defense capstone uses a fictional case-study organization and does not describe work for a real client. The public Incident Response Plan copy replaces the original assignment memo, removes other students' names, and omits the individual AI-use disclosure page.

## Content accuracy

Professional summaries cover security data pipelines, exception reconciliation, Python/FastMCP report-query tools, scanner investigation, CycloneDX SBOM collection, and developer support. Content is based on Sam’s supplied experience descriptions; no numerical impact, audit-compliance guarantee, or production-performance claim is made. Core AppSec tools are distinguished from broader tool familiarity. Academic projects and the home lab are identified as such. Projects appear before the interactive toolkit so visitors reach public evidence sooner. The VIN project is identified as a solo semester project, consistent with its project roadmap; the incident response project identifies Sam's team-lead contribution. The dashboard link identifies its screenshot destination, and the assessment presentation links directly to its video.

The Smart VIN Decoder description reflects its public implementation: basic input checks, NHTSA API requests, JSON parsing, and session-only in-memory history. It does not claim persistent storage, full-response caching, or comprehensive network error handling.

## Dice interaction

The D20 lands on a random value from 1 through 20. Its result is announced after the animation, and the third completed roll reveals a LinkedIn link. Rapid clicks during a roll are ignored. Reduced-motion mode skips the number shuffle.
